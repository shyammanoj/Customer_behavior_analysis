# 📊 Customer Behaviour Analysis Project

📌 **Project Overview**
This project focuses on analyzing customer behavior using a structured data analytics workflow. The objective is to clean raw customer data, calculate key business metrics, and generate interactive visual insights to better understand customer purchasing patterns and revenue trends.

The project demonstrates end-to-end data analysis using:
Python for Data Cleaning
SQL for Business Metric Calculation
Power BI for Data Visualization

🗂️ **Dataset**
Source: Customer Behaviour Dataset (CSV file)

🧹 **Step 1: Data Cleaning (Python)**

Using Python (Pandas & NumPy), the following data preprocessing steps were performed:
Removed duplicate records
Handled missing/null values
Corrected inconsistent data formats (dates, categorical values)
Standardized column names
Converted data types for accurate analysis
Created derived columns (e.g., Month, Year, Total Revenue)
This ensured the dataset was clean, structured, and ready for analysis.

🛢️ **Step 2: Business Metrics Calculation (SQL)**
After cleaning the data, SQL was used to extract key performance metrics such as:
💰 Total Revenue
📦 Total Orders
👥 Unique Customers
📈 Frequency of Purchases

🔁 Customer Purchase Frequency
These metrics helped in understanding overall business performance and customer engagement patterns.

📊 **Step 3:** **Data Visualization (Power BI)**

Power BI was used to create interactive dashboards to visualize insights such as:
Revenue trends over time
Top-performing products/categories
Customer segmentation insights
Regional sales distribution
Repeat vs New customer analysis
The dashboard enables stakeholders to quickly identify patterns and make data-driven decisions.

🔍 **Key Insights**
Identified revenue-driving customer segments
Observed seasonal purchasing behavior
Measured customer retention and repeat purchase patterns
Analyzed revenue contribution by product category

🛠️ **Tech Stack**

Python (Pandas, NumPy)
SQL (MySQL / PostgreSQL / SQL Server)
Power BI
CSV Dataset

🎯 **Business Impact**

This project demonstrates how raw customer data can be transformed into actionable insights through:
Data Cleaning
Metric Engineering
Business Intelligence Visualization
The analysis helps businesses understand customer behavior, optimize marketing strategies, and improve revenue performance.

🚀 **How to Run the Project**

Clone the repository
Open and run the Python data cleaning script
Load the cleaned dataset into SQL
Run SQL queries to generate metrics
Import the final dataset into Power BI to view the dashboard
